# Cobalt Clippings Sync

An Obsidian plugin that pushes Web Clipper notes to the [Clippings](https://github.com/BandarLabs/Cobalt) app on a Kobo running Cobalt, and merges read/tag changes back into each note's frontmatter.

Install via [BRAT](https://github.com/TfTHacker/obsidian42-brat) using this repository's URL. Full setup instructions coming soon.
